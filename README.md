# 🐾 PetCare Express

Sistema de gestión académico para clínicas veterinarias.  
Desarrollado como proyecto universitario con HTML, CSS y JavaScript vanilla.

## 🌐 Demo en vivo

**[https://Nicolas723.github.io/petcare-express/](https://Nicolas723.github.io/petcare-express/)**

## ✨ Funcionalidades

| Módulo | Descripción |
|---|---|
| **Planes y servicios** | Catálogo de planes, activación/desactivación, creación de servicios |
| **Mascotas** | Registro de dueños y mascotas con condiciones especiales |
| **Citas** | Programación con validación de disponibilidad y asignación automática de personal |
| **Tratamientos** | Registro de tratamientos e historial filtrable por mascota y tipo |
| **Personal** | Gestión de personal, especialidades, tarifas y agenda |

## 👥 Roles simulados

- **Administrador** – acceso completo
- **Dueño de mascota** – ve sus mascotas, citas y planes
- **Personal de servicio** – gestiona sus citas y registra tratamientos

## 🗂️ Estructura del proyecto

```
petcare-express/
├── index.html   # Estructura HTML
├── styles.css   # Estilos y sistema de diseño (dark mode incluido)
├── app.js       # Lógica completa de la aplicación
└── README.md
```

## 🚀 Uso local

Simplemente abre `index.html` en tu navegador — no requiere servidor ni dependencias.

> Los datos se guardan en `localStorage` del navegador.
